skincare app 

AI-powered skincare app built with React.js + Claude AI API. Generates personalized skincare routines based on skin type and concerns. My first full-stack project.

## Features
- Get personalized skincare routines based on skin type & concerns
- Clean, responsive UI with Tailwind CSS
- Instant AI suggestions using Claude API

## Tech Stack
React, Tailwind CSS, Claude AI API
